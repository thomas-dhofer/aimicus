# aimicus
A Swift app that gives you a clean and simple UI to use Ollama on macOS.

<img width="1280" height="720" alt="Dokument" src="https://github.com/user-attachments/assets/f1ceaaed-bd66-4a0b-9f4c-47a9f86187ec" />

## Features
* Runs discreetly as a `MenuBarExtra` in your macOS menu bar for easy accessibility.
* Clean native SwiftUI for a seamless integration.

## Requirements
* **Xcode**: compatible with macOS 26+ (or your current version)
* **Ollama**: recommended model --> gemma4:e2b

## Setup and Build
1. Ensure Ollama is running locally on your Mac.
2. Clone this repository.
3. Open `aimicus.xcodeproj` in Xcode.
4. Press `Cmd + R` to build and run the app.
